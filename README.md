# Tripleten web_project_around_pt

## 📱 Sobre o projeto
Este projeto é parte do curso de desenvolvimento web e consiste na criação da base do projeto "Around The U.S.", uma página interativa onde os usuários poderão adicionar, remover e curtir fotos. O objetivo inicial é separar os dados do código de marcação, utilizando JavaScript para popular e manipular os cartões de fotos dinamicamente.

## ⚙️ Funcionalidades
- Separação dos dados do HTML para um arquivo JavaScript;
- Criação de um array de objetos contendo as informações iniciais dos cartões;

## 🛠️ Tecnologias e técnicas utilizadas
- HTML5, para a estruturação do conteúdo;
- CSS3, para a estilização;
- JavaScript, para a lógica e manipulação dinâmica dos dados através de arrays e objetos.
